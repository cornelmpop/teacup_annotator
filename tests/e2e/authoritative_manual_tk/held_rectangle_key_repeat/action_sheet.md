# Held rectangle key-repeat workflow

Human recording performed against the `master_2` real-Tk fixture.

1. In **Open last folder**, click **OK**.
2. In **Choose annotation classes**, choose **Use annotation/default classes**.
3. In **Use model.conf?**, click **Yes**. Wait until the project is fully loaded and the canvas is visible.
4. Click once with the left mouse button in an empty part of the canvas to give the canvas keyboard focus.
5. Press and hold down **r**. Continue holding it for at least one full second before beginning the next step so macOS key repeat has started.
6. While still holding **r**, drag one obvious rectangle in an empty part of the image. Release the mouse button, continue holding **r** for another full second after the rectangle appears, and then release **r**.
7. Press and release **Escape** once to cancel any second rectangle mode started by a legitimate post-drag repeat. Wait until normal mode is restored.
8. Click **Save** and wait until saving finishes.
9. Close the window using the macOS close control. If an unexpected prompt appears, record its title and buttons and report it as a deviation.
